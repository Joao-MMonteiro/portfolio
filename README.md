# Portfólio — João Monteiro

Site estático em HTML, CSS e JavaScript puro.

## Estrutura
- `index.html`: página inicial com prévias dos cinco projetos.
- `projects/`: páginas de detalhe de cada projeto.
- `assets/images/`: imagens usadas nas capas e galerias.
- `css/style.css`: estilos e responsividade.
- `js/main.js`: menu mobile e animações de entrada.

Abra `index.html` em um navegador ou publique a pasta em qualquer hospedagem estática.
